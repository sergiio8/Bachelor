# Bachelor's Portfolio

A curated index of academic coursework and software projects developed during my bachelor's studies. The repositories below remain independent projects; this repository provides a single place to browse them.

## Academic coursework

- [Clustering](https://github.com/sergiio8/Clustering) — Exploratory analysis of loan-default data using clustering methods.
- [NLP](https://github.com/sergiio8/NLP) — Coursework experiments in text classification and neural language models.
- [NeuralNetworks](https://github.com/sergiio8/NeuralNetworks) — Machine-learning coursework on wine-quality prediction and model evaluation.
- [GeneticAlgorithms](https://github.com/sergiio8/GeneticAlgorithms) — Genetic-algorithm coursework, including propeller-design experiments.
- [ReinforcementLearning](https://github.com/sergiio8/ReinforcementLearning) — Tabular Q-learning experiments with Gymnasium's CartPole environment.
- [ComputationalAlgebra](https://github.com/sergiio8/ComputationalAlgebra) — C++ coursework in computational algebra and polynomial algorithms.
- [MARP1 problems](https://github.com/sergiio8/MARP1_problems) — C++ algorithms and problem-solving coursework.
- [MARP2 problems](https://github.com/sergiio8/MARP2_problems) — C++ algorithm coursework and online-judge exercises.

- [Plants vs. Zombies-inspired game](https://github.com/sergiio8/PlantsVSZombies) — Java terminal-based turn-based survival game.
